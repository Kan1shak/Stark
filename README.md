# Stark

A collaborative project management platform designed for university students to connect and work together across different fields of study.

## Features

- **Cross-Field Collaboration**: Connect with students across 20+ different fields
- **Project Discovery**: Find relevant projects with optimized search and filtering
- **Secure Authentication**: Robust user authentication and authorization system
- **Task Management**: Create, assign, and track project tasks
- **Real-time Updates**: Stay informed about project progress and changes

## Tech Stack

- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Frontend**: EJS, HTML, CSS
- **Testing**: nodriver.py
- **Authentication**: JWT
